## Project Introduction
This project is modified based on the official SDK of Unitree Qmini robot.

### Modification Details
1. **Controller Keys**: Adapted for self-defined gamepad, all button mapping configurations are revised.
2. **Initial Standing Posture**: Modified each joint's initial angle and position parameters of the robot default stance.
3. **USB Wiring**: Original USB cable is replaced with 4-channel wiring layout; corresponding motor IDs and wiring definitions are adjusted synchronously.

All remaining source codes inherit from the original Qmini official SDK without extra modification.
The project is still under ongoing debugging and optimization.

I’m an undergraduate student developing this Qmini-related project independently by hands-on debugging and coding.
Any suggestions, corrections and feedback from the community are warmly welcomed!

### 项目简述
本项目基于宇树Qmini官方SDK二次修改开发：
1. 手柄按键：适配自研自定义手柄，重新修改全部按键映射；
2. 初始站姿：修改机器人开机默认站姿各关节初始位置参数；
3. USB接线：原USB接线改为四路线路，同步调整电机编号与接线对应关系；

其余代码沿用原版Qmini SDK内容，项目目前处于持续调试阶段。
本人在校本科生，自主从零手搓开发本Qmini机器人项目，欢迎各位大佬批评指正、提出修改建议！
